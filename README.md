# NovaCart: SOC Monitoring & Log Analysis Dashboard

A beginner cybersecurity project focused on security log analysis, alert detection, and SOC dashboard monitoring using Python and Streamlit.

## Introduction

This project uses the NovaCart web application as a source of application activity and security logs. A separate SOC dashboard was developed to analyze log data, identify selected suspicious activity, and display security information in a visual interface.

## Objectives

- Analyze application security logs.
- Detect suspicious patterns, including repeated failed login attempts.
- Generate structured security alerts.
- Monitor activity associated with IP addresses.
- Present security information through a dashboard.

## Tools & Technologies

- Kali Linux
- Python
- Streamlit
- Pandas
- Plotly
- JSON / JSONL

## Dashboard Components

- Security Overview
- Security Event Distribution
- Recent Security Alerts
- IP Address Monitoring
- Security Event Details
- Automatic Dashboard Refresh

## Work Completed

- Developed a Python-based security log analyzer.
- Implemented detection for repeated failed login activity.
- Generated alerts with severity classification.
- Stored alert records in JSONL format.
- Built a Streamlit SOC dashboard.
- Added event summaries, alert monitoring, and IP activity monitoring.
- Tested alert generation using sample log events.
